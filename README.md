# rock-paper-scissors
## DESCRIPTION

Play the classic game of Rock-Paper-Scissors against the computer.

## Getting Started

To get started with this game, simply open the `index.html` in a web browser.

### Play the Game

Click on a picture to select a weapon (Rock, Paper, or Scissors) to compete against the computer's randomly selected weapon.

### Viewing Results

- Each round will display the computer and player choices as well as who won the round.

- Results on the main screen will be displayed temporarily before starting each new round.

- The scoreboard will keep a running tally throughout the game.

- You may also view the results in the console of your webDev tools. (One possible way of opening this is by pressing the F12 key in your browser.) 

### How to Win

- The first player to win 5 rounds wins the game.
